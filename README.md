# 🚆 코레일 차량정비 안전교육·테스트 웹 앱

KOSHA(한국산업안전보건공단) 공공데이터 **「사망사고 고위험요인(SIF) 아카이브」**에서 실제 중대재해 사례 19건을 선별해
한국철도공사(코레일) **차량정비 분야**에 맞춰 학습·테스트하는 정적 웹 앱입니다.
빌드 과정 없이 `index.html`을 여는 것만으로 동작하며, GitHub Pages·정적 서버 어디에나 올릴 수 있습니다.

## 주요 기능

| 탭 | 내용 |
| --- | --- |
| **홈(대시보드)** | 앱 소개, KOSHA 공공데이터 출처·이용허락 표기, 내 학습 완료율·최근 테스트 점수·응시 횟수(localStorage) |
| **사고사례 학습** | 위험 유형 필터(전체 / 끼임·깔림 / 감전 / 추락 / 크레인·중량물 / 구내·선로), 사례별 재해개요·기인물·고위험작업·재해유발요인·위험성 감소대책(KOSHA 원문) + 차량정비 적용 포인트·관련 법규(앱 해설), ‘학습 완료’ 토글 |
| **안전 테스트** | 사례 기반 4지선다 19문항, 랜덤 10문항 / 전체 풀기 선택, 선택 즉시 정답·오답 및 해당 사례·대책·법규 해설, 종료 시 점수·합격 여부(80점 이상)·오답 노트·재응시(같은 방식 / 틀린 문항만) |
| **TBM 체크리스트** | 차량정비 착수 전 LOTO·검전·접지·안전블록·안전대·줄걸이·열차감시원·지게차 등 9개 그룹 38항목, 진행률 표시, 전체 초기화 |

- **모바일 최적화**: 반응형 레이아웃 + 하단 탭바, `apple-mobile-web-app-capable`·`theme-color`·`manifest.webmanifest`(PWA 메타) 포함
- **오프라인 친화**: 외부 라이브러리·CDN·폰트 요청 없음, 모든 자산이 저장소 안에 있음
- **저장**: 학습 완료·점수·체크 상태는 브라우저 `localStorage`에만 저장(서버 전송 없음)

## 파일 구조

```
korail-safety-app/
├── index.html                  # 화면 골격(4개 탭)
├── style.css                   # 네이비·코레일 블루 + 앰버/레드 포인트, 반응형
├── app.js                      # 탭·학습·테스트·TBM 로직(localStorage 연동)
├── data.js                     # KOSHA 원문 사례 19건 + 퀴즈 19문항 + TBM 38항목
├── manifest.webmanifest        # PWA 매니페스트
├── icons/                      # 앱 아이콘(SVG·PNG 192/512/maskable·apple-touch)
└── README.md
```

## 데이터 출처와 이용 조건

- **데이터**: 한국산업안전보건공단_사망사고 고위험요인(SIF) 아카이브 (파일데이터, 2026-04-01 갱신본)
  - 공공데이터포털: <https://www.data.go.kr/data/15140383/fileData.do>
  - 고용노동부 정책자료실 배포 파일: <https://www.moel.go.kr/policy/policydata/view.do?bbs_seq=20260400196>
  - 수록 범위: 2016~2023년 중대재해 6,032건(제조업 등 2,573건 · 건설업 3,459건)
- **이용허락범위**: 공공저작물 제3유형 — **출처표시, 변경금지**
  - 따라서 `data.js`의 `summary`(재해개요)·`object`(기인물)·`highrisk`(고위험작업·상황)·`precursor`(재해유발요인)·`measure`(위험성 감소대책)는 **원문 텍스트를 수정 없이 그대로** 인용했습니다.
  - 사례별 `point`(차량정비 적용 포인트), `laws`(관련 법규 해설), `QUIZ`(테스트 문항), `TBM_GROUPS`(체크리스트)는 이 앱을 위해 별도로 작성한 내용이며 화면에서도 구분해 표시합니다.
- 원문 자료는 동종재해 예방 목적의 자료로, 일부 내용이 실제 재해 상황과 다를 수 있습니다.

- 관련 법규는 「산업안전보건기준에 관한 규칙」(2026-03-02 시행, 고용노동부령 제450호) 조문 기준입니다.

## 로컬 실행

```bash
cd korail-safety-app
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 파일로 직접 열어도 동작하지만, PWA 매니페스트·아이콘 확인은 정적 서버 실행을 권장합니다.

## 배포

GitHub Pages: 저장소 `main` 브랜치의 `/ (root)`를 지정하면 `https://<계정>.github.io/korail-safety-app/` 으로 게시됩니다. 별도 빌드가 필요 없습니다.
